    Gig

    Muralista owns visuals.json and writes it into this folder beside gig.json, which it only ever reads — song ids, song titles and the venue, and nothing below that line. Lyrics preview with a fixed dummy line, which is what keeps the line there.

    Media folder

    Layer sources are looked up inside this folder, by name — the mapping stores the name, never the folder. A name the folder does not have falls back to the served directory, so a mapping made elsewhere still opens.

    Backdrop

    Authoring aid only (planning canvas) — shown at reduced opacity under the surface outlines, never sent to the output.
